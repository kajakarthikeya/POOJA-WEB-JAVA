🎯 1. Aim

To write and execute a Java program (AccessDemo.java) to connect to a Microsoft Access database (.accdb/.mdb) using UCanAccess JDBC driver and display records.

📖 2. Short Introduction

UCanAccess is a pure Java JDBC driver implementation that allows Java applications to read and write to Microsoft Access database files without requiring ODBC DSN configuration on Linux or Windows platforms.

⚙️ 3. System Requirements

🖥️ Hardware Requirements

RAM: 4 GB
Storage: 300 MB free space
💾 Software Requirements
OS: Ubuntu / Linux / Windows
JDK: Java SE 8+
JDBC Driver: ucanaccess-5.1.3.jar & dependencies

import java.sql.*;

public class AccessDemo {
    public static void main(String[] args) {
        try {
            Class.forName("net.ucanaccess.jdbc.UcanaccessDriver");
            String url = "jdbc:ucanaccess://StudentDB.accdb";
            Connection con = DriverManager.getConnection(url);

            System.out.println("Connected Successfully");

            Statement st = con.createStatement();
            ResultSet rs = st.executeQuery("SELECT * FROM Student");

            while (rs.next()) {
                System.out.println(rs.getInt(1) + " " + rs.getString(2) + " " + rs.getInt(3));
            }
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

📝 6. Program Explanation

Step Code Line Description
Load Driver Class.forName("net.ucanaccess.jdbc.UcanaccessDriver") Registers UCanAccess JDBC driver.
Connect URL jdbc:ucanaccess://StudentDB.accdb Connects directly to MS Access database file.
Query Execution st.executeQuery("SELECT * FROM Student") Retrieves student ID, Name, and Marks.
