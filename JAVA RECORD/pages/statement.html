🎯 1. Aim

To write and execute a Java program to invoke MySQL Stored Procedures (InsertPerson and DeleteDepartment) using JDBC CallableStatement and display person and department details.

📖 2. Short Introduction

MySQL Stored Procedures execution SQL from lab manual:

MySQL Stored Procedures Schema 
CREATE TABLE Person (
  PersonID INT,
  FirstName VARCHAR(255),
  City VARCHAR(255)
);

DELIMITER $$
CREATE PROCEDURE InsertPerson(
  IN pid INT,
  IN pname VARCHAR(255),
  IN pcity VARCHAR(255)
)
BEGIN
  INSERT INTO Person VALUES(pid, pname, pcity);
END$$
DELIMITER ;

package javaapplication26;

import java.sql.*;

public class ProcedureDemo {
    public static void main(String[] args) {
        try {
            Class.forName("com.mysql.jdbc.Driver");
            Connection con = DriverManager.getConnection("jdbc:mysql://localhost/it", "root", "");

            // Call InsertPerson Procedure
            CallableStatement cs = con.prepareCall("{call InsertPerson(?,?,?)}");
            cs.setInt(1, 101);
            cs.setString(2, "Rahul");
            cs.setString(3, "Hyderabad");
            cs.execute();

            System.out.println("Record Inserted Successfully\n");
            System.out.println("Person Details");

            Statement st = con.createStatement();
            ResultSet rs = st.executeQuery("SELECT * FROM Person");
            while (rs.next()) {
                System.out.println(rs.getInt(1) + " " + rs.getString(2) + " " + rs.getString(3));
            }
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

📝 6. Program Explanation

Component Code Line Explanation
CallableStatement con.prepareCall("{call InsertPerson(?,?,?)}") Prepares SQL stored procedure execution.
Parameter Binding cs.setInt(1, 101); cs.setString(2, "Rahul"); Binds IN parameters to procedure call.
Procedure Execution cs.execute() Executes stored procedure inside MySQL server.
