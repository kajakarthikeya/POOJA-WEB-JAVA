Task 1: Remote MySQL Database Connectivity

🎯 1. Aim

To establish a secure remote database connection from Java to a remote MySQL 8.0 server over TCP/IP port 3306 using the Type-4 MySQL Connector/J driver, instantiate a Statement object, execute an INSERT query to add employee record ('9', 'Pooja') into the remote employee table, and verify transaction persistence.

⚙️ 2. Hardware & Software Requirements

💻 Software Environment
IDE: NetBeans IDE 8.2 with JDK 8+
JDBC Driver: MySQL Connector/J 8.0.x (Type-4 Pure Java)
Database Server: MySQL Community Server 8.0
Database URL: jdbc:mysql://<remote-ip>:3306/it
🌐 Network Parameters
Port: 3306 (TCP bidirectional socket)
Authentication: Remote user credentials with grant permissions
Target Table: employee (rollno VARCHAR, name VARCHAR)

☕ JavaApplication59.java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

public class JavaApplication59 {
    public static void main(String[] args) {
        try {
            // Step 1: Register MySQL Connector/J Driver
            Class.forName("com.mysql.cj.jdbc.Driver");
            
            // Step 2: Establish Remote Connection (Port 3306)
            String url = "jdbc:mysql://10.0.9.44:3306/it";
            Connection con = DriverManager.getConnection(url, "student", "student");
            System.out.println("Connected Successfully to Remote MySQL DB");
            
            // Step 3: Create Statement
            Statement stmt = con.createStatement();
            
            // Step 4: Insert Record
            String sqlInsert = "INSERT INTO employee VALUES('9', 'Pooja')";
            int rows = stmt.executeUpdate(sqlInsert);
            System.out.println("Record Inserted Successfully (" + rows + " row affected)");
            
            // Step 5: Read and Display
            ResultSet rs = stmt.executeQuery("SELECT * FROM employee");
            while (rs.next()) {
                System.out.println(rs.getString(1) + " : " + rs.getString(2));
            }
        } catch (Exception e) {
            System.out.println("Database Error: " + e.getMessage());
        }
    }
}

📊 6. Result Analysis & Discussion

🔍 Remote TCP Socket Communication

Type-4 MySQL Connector/J driver opens a dedicated TCP/IP network socket on port 3306 directly with the remote MySQL daemon, converting Java method invocations into MySQL binary client-server protocol packets with minimal latency.

⚡ Driver Loading & Service Provider (SPI)

While Class.forName("com.mysql.cj.jdbc.Driver") explicitly registers the driver class, modern JDBC 4.0+ automatically discovers drivers via META-INF/services/java.sql.Driver SPI, ensuring high backward compatibility.

🛡️ Remote Access Grants & Firewalling

Connecting across subnets requires MySQL user grants for specific remote host IPs (GRANT ALL ON it.* TO 'student'@'%') and opening inbound TCP port 3306 on the host firewall (ufw allow 3306/tcp).

💡 DML Execution Return Codes

Calling executeUpdate() returns an integer count indicating exactly how many rows were inserted, updated, or deleted, allowing the application layer to verify transaction success before committing.
