☕ DBConnection.java
import java.sql.Connection;
import java.sql.DriverManager;

public class DBConnection {
    private static Connection con;
    public static Connection getConnection() {
        try {
            if (con == null || con.isClosed()) {
                Class.forName("com.mysql.cj.jdbc.Driver");
                con = DriverManager.getConnection(
                    "jdbc:mysql://localhost:3306/studentdb", "root", ""
                );
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
        return con;
    }
}

📊 6. Result Analysis & Discussion

🔍 Stateless HTTP vs State Management

HTTP is fundamentally stateless. The Java Servlet API provides two orthogonal state preservation models: lightweight client-stored Cookie headers and secure server-side HttpSession state maps bound to unique cookie tokens.

⚡ Connection Pooling in Multi-Servlet Environments

Instantiating a singleton DBConnection utility prevents rapid socket churn, ensuring multiple concurrent servlets (Add, Display, Search) share recycled database handles rather than spawning costly TCP handshakes per HTTP request.

🛡️ Cookie Security & Session Fixation

Cookies containing authentication data must be protected with HttpOnly (blocking JavaScript XSS reads), Secure (requiring TLS encryption), and SameSite=Strict (mitigating Cross-Site Request Forgery - CSRF).

💡 MVC Architectural Decoupling

Separating SQL queries into DAO classes, business routing into HttpServlet subclasses, and presentation into dynamic HTML/JSP templates maintains high modularity, allowing independent updates to database schemas and UI layouts.
