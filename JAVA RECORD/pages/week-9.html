<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.1.2</version>
        <relativePath/>
    </parent>

    <groupId>com.example</groupId>
    <artifactId>springmavendemo</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <name>springmavendemo</name>

    <properties>
        <java.version>17</java.version>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>

📊 7. Result Analysis & Discussion

🔍 Maven Dependency Management & BOM

spring-boot-starter-parent acts as a centralized Bill of Materials (BOM), locking compatible versions for over 150 third-party libraries (Jackson, Tomcat, SLF4J), completely eliminating classpath jar conflicts.

⚡ Embedded Container Architecture

Spring Boot packages an embedded Apache Tomcat engine inside executable fat JARs (spring-boot-maven-plugin), eliminating manual WAR generation and external servlet container deployments.

🛡️ Auto-Configuration & Conditionals

Through @ConditionalOnClass and @EnableAutoConfiguration, Spring Boot inspects the classpath and instantiates necessary beans (DispatcherServlet, Jackson JSON converters) only when dependencies exist.

💡 Multi-Port Isolation & Microservices

Configuring independent server ports (8080 and 8081) in application.properties demonstrates modular microservice process isolation on the same physical host machine.
